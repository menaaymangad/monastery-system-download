# تطبيق إدارة مزرعة الدير — تحميل نسخة Android

## طريقة التثبيت

1. اضغط على رابط الـRelease: [أحدث إصدار](https://github.com/menaaymangad/monastery-system-download/releases/latest)
2. نزّل ملف APK المسمّى `monastery-system-android.apk`
3. لو Android طلب السماح بالتثبيت من هذا المصدر، فعّلها
4. افتح التطبيق بعد التثبيت

رابط التحميل المباشر:
